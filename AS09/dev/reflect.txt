In this assignment, I learned and reviewed how the Rule of Three works together with inheritance. I recalled that the copy constructor is used when a new object is created from an existing object, while the assignment operator is used when both objects already exist. For the copy constructor, I had to explicitly call Marks(t) in the initialization list (:Marks(t))for base class portion copy while I had to call Marks::operator=(t) for Copy Assignment Operator.
I also reused Utils::alocpy() to manage the student name. This function deletes the previous memory, allocates new memory, and performs a deep copy as what instructions required.
One difficulty I encountered was defining the default argument for display(). The compiler reported a redefinition error, and I learned that a default argument should only be declared in the header file. 
Overall, this assignment improved my understanding of inheritance, overriding, dynamic memory, the Rule of Three, deep copying, and self-assignment.
